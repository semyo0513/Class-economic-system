# 🌲 클래스 타운 (Class Town)
> **동물의 숲 2D 학급경영 & 싸이월드 미니룸 웹앱**

Google Apps Script(구글 시트 10개 DB) 기반 학급 경제 시스템(클래스뱅크 LMS)을 Phaser 3 엔진과 연동하여 탑다운 2D 타운 게임 및 하우징 시스템으로 구현한 웹앱입니다.

---

## 🌟 주요 기능
1. **학생 기숙사 & 싸이월드 미니룸 (하우징)**
   - 20여 종의 픽셀아트 가구/인테리어 소품/펫을 학급 화폐로 구매하여 내 방 꾸미기 및 실시간 배치.
   - 친구들의 방을 방문하고 'Today's Story' 상태메시지 확인, 방명록(일촌평) 작성 및 좋아요(❤️).
2. **14개 건물 경제 & LMS 시스템**
   - **주거구역**: 학생 기숙사 (미니룸 포털)
   - **금융구역**: 은행 (예금/이자), 증권거래소 (실시간 주가 차트/매수/매도), 부동산 중개소 (교실 좌석 배치도)
   - **상업구역**: 잡화점 & 가구점, 학급마트 (바코드/간편 결제), 행운의 복권방 (즉석 긁는 복권)
   - **행정구역**: 시청 (임원 전용 상벌점/공지 권한), 고용센터 (1인 1직업 채용/지원), 우체국 (송금/칭찬카드)
   - **교육구역**: 학교 본관 (과제 제출, 숙제 체크, 급식 식단표, 시간표, 교사 호출), 상담실 (감정 신호등 보상 수령)
   - **공원구역**: 중고 벼룩시장 (노점 장터)
3. **교사용 [🏫 교장실 (관리자 설정)] 상단 퀵 HUD**
   - 교사 로그인 시 상단 HUD에 퀵 버튼이 상시 노출되어 원클릭으로 학생 자산 조정, 경제 정책, 주가 조절, 과제 관리 가능.
4. **실시간 멀티플레이어 & 사운드**
   - Firebase Realtime Database를 통한 다른 친구들의 실시간 위치 동기화 및 머리 위 실시간 말풍선 채팅.
   - Web Audio API 기반 레트로/코지 사운드 효과음 및 감성 BGM 내장.

- **프론트엔드**: HTML5, CSS3, JavaScript (ES6+), Phaser 3
- **백엔드/데이터베이스**: Google Apps Script (`code.gs`), Google Sheets (10개 시트)
- **실시간 통신**: Firebase Realtime Database & Anonymous Auth
